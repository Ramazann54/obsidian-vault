## Условие (кратко)
Буквы a–i кодируются цифрами 1–9, буквы j–z — числами 10#–26#.
Дана закодированная строка, нужно восстановить исходную.

## Идея
Смотрим на символ **через два** от текущего:
- если `s[i+2] == '#'` → двузначный код `s[i:i+2]`, сдвиг на 3 символа;
- иначе → однозначный код `s[i]`, сдвиг на 1.

Шаг бывает разный, поэтому `while`, а не `for`.

## Ловушки
- Перед `s[i+2]` проверить длину: `len(s) >= 3`, иначе IndexError.
  `and` не проверяет правую часть, если левая ложна.
- Двузначный код занимает 3 символа: две цифры + `#`.
- Ответ нужно `print`, а не `return`.

## Мой код
```python
import sys
def main():
n = str(input())
word = ""
two_digit = {"10":"j", "11":"k", "12":"l","13":"m","14":"n","15":"o","16":"p","17":"q","18":"r","19":"s","20":"t","21":"u","22":"v","23":"w","24":"x","25":"y","26":"z"}
one_digit = {"1":"a","2":"b","3":"c","4":"d","5":"e","6":"f","7":"g","8":"h","9":"i"}
while n:
if(len(n)>=3 and n[2]=="#"):
word+=two_digit.get(n[:2])
n = n[3:]
else:
word+=one_digit.get(n[:1])
n = n[1:]
print(word)
if __name__ == '__main__':
main()
```
`chr(ord('a') + k - 1)` — буква по номеру, вместо словаря.
